# A股操盘台 · Command Center

高级操盘手工作台：盘前情报 → 盘中跟踪 → 盘后复盘。

## 功能
- **指挥舱**：市场温度计 0-100 · 状态（进攻/偏多/震荡/防守/空仓）· 今日操盘剧本
- **持仓矩阵**：现价 / 涨跌 / 浮盈 / 信号（加·持·减·损·望）/ 止损止盈位 / 仓位建议
- **细分板块资金流分时折线**：行业 + 概念板块主力净流入 · **盘中每 1 分钟采样** · Canvas 多线图
- **板块轮动**：主力资金流向热力
- **情报流**：30 分钟滚动情报
- **连板梯队 / 财经快讯 / 每日复盘 / 分析快照**

## 更新节奏
| 时段 | 频率 |
|------|------|
| **开盘期间** | **每 30 分钟**全量刷新（Actions） |
| **细分板块资金流折线** | **盘中每 1 分钟**浏览器采样 |
| 盘中前端行情 | 每 30 秒快照 |
| 收盘后 17:00 | 每日复盘 |
| 盘前 08:30 | 盘前情报 |

## 技术
- 纯静态 `index.html`（GitHub Pages）
- GitHub Actions 定时跑 Python：
  - `trader_engine.py` 市场温度 + 个股信号 + 操盘建议
  - `market_clock.py` A股交易时段
  - `sector_flow.py` 细分板块资金流（行业+概念 Top + 分钟序列）
  - `lianban_scanner.py` 连板扫描
  - `news_fetcher.py` 财经新闻
  - `portfolio_tracker.py` 持仓跟踪
  - `tools/*` 行情快照 / 情报合并
